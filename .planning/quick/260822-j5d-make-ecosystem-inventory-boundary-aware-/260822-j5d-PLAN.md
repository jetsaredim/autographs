# Quick Task 260822-j5d Plan

## Task 1: Classify repository sources and VM env files

Derive variable boundaries from executable source locations rather than names.
Allow variables to span multiple boundaries, but use `documentation-only` only
when no executable/example source exists. Classify VM env files as runtime,
smoke, or other without reading their values.

## Task 2: Make comparison semantics boundary-aware

Compare runtime env files to Ansible's deployed runtime templates. Report
controller-consumed variables that are absent from both the template and VM as
defaulted/optional review information. Keep smoke drift separate, list external
repository boundaries without comparing them to the VM, and calculate actual
pairwise env-key intersections.

## Task 3: Preserve compatibility and prove behavior

Render current schema-1 inventories using source-path fallback, bump newly
generated inventories to schema 2, add focused fixtures for deploy-only keys,
runtime defaults, smoke separation, and overlap, then regenerate committed
repository evidence and run repository validation.

Purpose: Prevent Renovate from updating workflow Terraform versions while leaving the composite action's fallback default behind.
Output: A focused `renovate.json` change whose file and value regexes match both current workflow pins and the composite-action default.
</objective>

Expand `managerFilePatterns` with a generic repo-root-relative pattern for nested `.github/actions/**/action.yml` and `action.yaml` definitions while retaining the workflow YAML pattern. Add a second `matchStrings` expression that starts at an exact line-bounded `terraform-version:` input key, stays within its four-space-indented input fields, and captures only the quoted `default` value as `currentValue`. Line-bound the workflow matcher around the exact `terraform_version:` key as well so longer sibling keys cannot be classified as HashiCorp Terraform. Retain `depNameTemplate: hashicorp/terraform`, `datasourceTemplate: github-releases`, and the `custom.regex` package-rule behavior. Update the manager description to end with `workflows and actions`. Do not modify `.github/actions/resolve-runtime-ip/action.yml`, `scripts/validate-terraform-version-alignment.py`, workflow pins, or unrelated Renovate rules.</action>

    <automated>python3 -m json.tool renovate.json &gt;/dev/null &amp;&amp; node -e 'const fs=require("fs"); const cfg=JSON.parse(fs.readFileSync("renovate.json","utf8")); const managers=cfg.customManagers.filter(x=&gt;x.depNameTemplate==="hashicorp/terraform"); if(managers.length!==1) throw new Error(`expected one Terraform manager, found ${managers.length}`); const m=managers[0]; const body=p=&gt;p.startsWith("/")?p.slice(1,p.lastIndexOf("/")):p; const fileMatch=p=&gt;m.managerFilePatterns.some(pattern=&gt;new RegExp(body(pattern)).test(p)); const workflows=fs.readdirSync(".github/workflows").filter(f=&gt;/\.ya?ml$/.test(f)).map(f=&gt;`.github/workflows/${f}`).filter(p=&gt;/terraform_version:\s*"[^"]+"/.test(fs.readFileSync(p,"utf8"))); if(workflows.length&lt;2) throw new Error(`expected both existing workflow pins, found ${workflows.length}`); const files=[...workflows,".github/actions/resolve-runtime-ip/action.yml"]; if(!files.every(fileMatch)) throw new Error("Terraform manager does not cover every pin file"); const captures=Object.fromEntries(files.map(file=&gt;{const text=fs.readFileSync(file,"utf8"); return [file,m.matchStrings.flatMap(pattern=&gt;[...text.matchAll(new RegExp(pattern,"g"))].map(match=&gt;match.groups.currentValue))]})); if(!files.every(file=&gt;captures[file].length===1)) throw new Error(`expected one Terraform capture per file: ${JSON.stringify(captures)}`); if(new Set(Object.values(captures).flat()).size!==1) throw new Error(`Terraform pins differ: ${JSON.stringify(captures)}`); console.log(JSON.stringify(captures,null,2));' &amp;&amp; python3 scripts/validate-terraform-version-alignment.py &amp;&amp; git diff --check -- renovate.json</automated>

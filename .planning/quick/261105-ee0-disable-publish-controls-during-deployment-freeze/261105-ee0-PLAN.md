# Disable publish controls during deployment freeze

The deployment freeze is enforced by exact Caddy routes that return 503 for both publish POSTs. The admin UI does not receive freeze state, so its three publish controls remain enabled.

1. Mark the authenticated, proxied publish status response when Caddy has installed the freeze routes. Preserve the existing server-side 503 gate.
2. Have the admin UI read that status, disable all publish controls while frozen or status is unavailable, show a clear reason, refresh while the page is open, and recheck immediately before publishing.
3. Cover frozen and normal Caddy routing, admin control wiring, and the relevant local validation gates.

The Caddy gate remains authoritative; the UI is an operator-facing reflection of its state.

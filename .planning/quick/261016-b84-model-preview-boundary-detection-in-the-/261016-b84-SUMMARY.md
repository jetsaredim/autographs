# Preview boundary measurement summary

Added a read-only boundary-location API to the shared image-processing crate and
kept the production auto-correction proposal contract unchanged. The boundary API
returns reliable, tentative, or unavailable results; it can expose near-identity
boundaries and select a coherent outer gradient rectangle when conservative color
segmentation identifies internal content or cannot isolate the card.

The local workbench now analyzes every rendered preview, initializes the orange
measurement quadrilateral from the detected boundary, and recalculates its edge
alignment automatically after adjustments. A tentative boundary is dashed.
Dragging an orange handle creates a browser-local manual override, and **Use
automatic detection** resumes per-render detection.

The saved reference fixture for image 7 returned a reliable live boundary with
corners `(0.0397, 0.0266)`, `(0.9436, 0.0266)`, `(0.9436, 0.9640)`, and
`(0.0397, 0.9640)`.

# Improve admin image review usability

## Scope

- Keep source and output previews visible beside compact, independently scrolling controls on wide screens; preserve a usable stacked layout on narrow screens.
- Restore draggable and keyboard-adjustable output-boundary corners for manual framing.
- Show side-specific alignment information with text and color, including the available measurement detail.
- Add a collapsed, read-only JSON view of saved and draft adjustment data for the selected image.

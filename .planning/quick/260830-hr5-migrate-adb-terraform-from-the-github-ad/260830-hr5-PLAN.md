Do not read a secret bundle, introduce a plaintext data source, add `secret_version_number`, duplicate the OCID in GitHub configuration, or couple the runtime root to tenancy remote state. **Verify:** Run `terraform -chdir=infra/terraform fmt -check -recursive -list=true -diff`.

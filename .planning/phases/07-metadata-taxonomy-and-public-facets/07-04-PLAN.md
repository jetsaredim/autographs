<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Private catalog -> public DTOs | Publisher transforms private Oracle/media-backed records into public-safe JSON and HTML. |
| Static JSON -> public browser | Anonymous browser filters generated data with URL-backed query state. |
| External profile links -> browser | Wikipedia/IMDb URLs leave the static site from detail pages only. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-04-01 | Information Disclosure | Public schema version 2 DTOs | mitigate | Static contract tests scan new signer/taxonomy fields for Object Storage identifiers, Oracle internals, image UUIDs, original filenames, unpublished records, and migration internals. |
| T-07-04-02 | Tampering | Detail HTML rendering | mitigate | Escape server-rendered signer/taxonomy text and restrict external profile links to optional Wikipedia/IMDb URLs with `rel=\"noopener noreferrer\"`. |
| T-07-04-03 | Denial of Service | Public facets mismatch | mitigate | Schema version 2 contract tests validate `collection.json`, `facets.json`, item JSON, detail HTML, and browse query params together before promotion. |
| T-07-04-04 | Spoofing | External profile links | mitigate | Visible icon links get explicit `aria-label` naming Wikipedia/IMDb and signer display name; full URLs are not displayed as trusted copy. |
| T-07-04-SC | Tampering | Package supply chain | mitigate | Use existing Rust/Serde and static browser APIs; no package installs are planned. |
</threat_model>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Controller -> Oracle | New repository methods modify signer relationships and taxonomy data. |
| Legacy export -> migration generator | Existing category/tag/signature values are transformed into review artifacts. |
| Generated PL/SQL -> operator SQL Developer | Human-reviewed script can mutate live Oracle data outside the controller runtime. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-02-01 | Tampering | `merge_signer_profiles` | mitigate | Require source and target signer IDs, reject self-merge, preserve target profile, update item credits transactionally, and record affected item history. |
| T-07-02-02 | Information Disclosure | Backfill report and PL/SQL | mitigate | Tests scan generated artifacts for Object Storage URLs, bucket names, object keys, Oracle connection strings, image UUIDs, and credentials. |
| T-07-02-03 | Repudiation | Backfill and merge operations | mitigate | Mapping file path and generated SQL comments identify the Phase 7 mapping source; signer merge records item edit-history events. |
| T-07-02-04 | Denial of Service | Oracle adapter joins | mitigate | Add indexes in 07-01 and use bounded suggestion query ordering so admin typeahead does not require full unbounded payloads. |
| T-07-02-SC | Tampering | Package supply chain | mitigate | Implement the CLI with `std::env::args`; no package-manager installs are planned. |
</threat_model>

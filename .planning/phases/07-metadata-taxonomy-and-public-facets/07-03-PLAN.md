<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser -> `/admin/api/*` | Authenticated operator input crosses into private controller routes. |
| Static admin JS -> DOM | Operator-controlled metadata is rendered in the browser. |
| Signer merge route -> repository | Destructive profile consolidation changes linked item credits. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-03-01 | Elevation of Privilege | New admin routes | mitigate | Use `authorize_admin_session` for every signer/taxonomy route and add bearer rejection tests. |
| T-07-03-02 | Tampering | `POST /admin/api/signers/merge` | mitigate | Require source/target IDs, reject self-merge, show destructive confirmation copy, and record merge history. |
| T-07-03-03 | Information Disclosure | Admin DTOs and diagnostics | mitigate | Return redacted camelCase DTOs only; tests deny Object Storage terms, Oracle internals, image UUIDs, and raw migration report contents. |
| T-07-03-04 | Tampering | Static admin rendering | mitigate | Render dynamic metadata with DOM nodes and `textContent`; no raw HTML injection for signer/taxonomy values. |
| T-07-03-SC | Tampering | Package supply chain | mitigate | Keep static HTML/CSS/JS and existing Rust dependencies; no package installs are planned. |
</threat_model>

## Taxonomy Cue Scope

Selected direction:

- Prioritize an event-ready starter set plus current catalog gaps.
- Support franchise, product line, non-default language, and set cues only when
  product line is filled in.
- Do not create format cues.
- Start with curated image thumbnails while preserving text fallback.

## Cue Creation And Approval

Selected direction:

- Most cue assets should come from dedicated uploads or web-sourced candidates.
- Research-assisted discovery is useful, but the first pass does not need an
  in-app web image search interface.
- Candidate assets may appear privately, but generated public output must
  include approved assets only.
- Review copyright/publication risk and source suitability before public use.

## Admin/Public Placement

Selected direction:

- Keep the signed item image as the hero.
- Put taxonomy cues inside the revealed detail metadata panel.
- Place cues after signers and integrate them with classification metadata.
- Use compact media-first visual tags with accessible labels and text fallback.
- Support rectangular assets such as card backs.

## Realignment

On 2026-07-28, this work moved from the old combined Phase 8 into Phase 9 so
Phase 8 can first repair operational posture and build admin media
preview/adjustment foundations. Advisory OCR/AI ingest moved to Phase 10.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| private source of truth -> public static release | Optimization must not leak private media coordinates or unpublished records. |
| public CDN/cache -> origin Caddy | CDN behavior must preserve TLS, rollback, cache freshness, and admin/API privacy. |
| repository cleanup -> production cleanup | Local docs/tests must not claim live VM cleanup unless an operator actually ran it. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-09-01 | Information Disclosure | generated derivatives/static JSON | high | mitigate | Keep privacy scans and contract tests over generated artifacts; never include original filenames, private object keys, image UUIDs, Oracle internals, or unpublished records. |
| T-06-09-02 | Information Disclosure | CDN/cache | high | mitigate | Exclude `/admin` and `/admin/api/*` from CDN caching guidance; document cookie/session privacy and origin-only admin behavior. |
| T-06-09-03 | Denial of Service | image optimization | medium | mitigate | Keep source-size limits, derivative dimensions, and encoding tests; avoid CPU-heavy processing in request paths. |
| T-06-09-04 | Tampering | CDN cache rollback | medium | mitigate | Document purge/rollback behavior and keep HTML/JSON cache freshness conservative. |
| T-06-09-05 | Elevation of Privilege | deployed instance cleanup | high | mitigate | Cleanup guidance must not broaden IAM, expose admin routes, or bypass approval for destructive production actions. |
| T-06-09-SC | Tampering | package supply chain | medium | mitigate | Avoid new dependencies unless clearly justified; if dependency changes are required, run normal Rust/CI checks and document why existing libraries were insufficient. |
</threat_model>

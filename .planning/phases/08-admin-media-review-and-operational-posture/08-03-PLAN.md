## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser -> Cloudflare -> Caddy | Public/admin requests may be cached or bypassed by CDN rules before reaching origin. |
| Publisher -> public static release | Generated HTML/JSON/media cacheability affects rollback and stale content behavior. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-03-01 | Information Disclosure | `/admin` and `/admin/api/*` via CDN | mitigate | Document Cloudflare bypass and preserve Caddy `Cache-Control: no-store` with source tests. |
| T-08-03-02 | Tampering | stale public derivatives after adjustment | mitigate | Require adjustment-aware fingerprinted `/media/*` URLs in the contract before media implementation. |
| T-08-03-03 | Denial of Service | over-broad purge/rollback | mitigate | Document emergency purge only and normal rollback through short-lived HTML/JSON plus fingerprinted media paths. |
</threat_model>

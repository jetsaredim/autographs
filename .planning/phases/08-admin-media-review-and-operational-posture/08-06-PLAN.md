<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser -> admin API | Admin preview/review/adjustment requests cross from browser to Rust controller. |
| Controller -> private media store | Preview generation reads private Object Storage/local media bytes. |
| Browser DOM -> operator | Error and preview state text is visible to the admin and must stay redacted. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-06-01 | Information Disclosure | preview URLs and errors | mitigate | Same-origin admin routes, no-store responses, generic browser errors, source tests for denied storage terms. |
| T-08-06-02 | Elevation of Privilege | adjustment mutation routes | mitigate | Use `authorize_admin_session` with method-aware CSRF/origin checks; no bearer-token media management compatibility. |
| T-08-06-03 | Tampering | draft adjustment UI | mitigate | Keep draft-local edits until explicit Save; reset uses confirmed DELETE route and repository validation. |
| T-08-06-04 | Denial of Service | preview decode/transform | mitigate | Reuse source byte limit and adjusted derivative generation from Plan 08-04. |
</threat_model>

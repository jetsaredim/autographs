| Property | Value |

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge internals, preview metadata stack |
| sm | 8px | Compact element spacing, button icon gaps, tile text rhythm |
| md | 16px | Default form/control gaps, tile padding, panel internals |
| lg | 24px | View-panel padding, page section gaps, sticky action bands |
| xl | 32px | Desktop admin-shell vertical padding, review view major gutters |
| 2xl | 48px | Major workflow separation when a full review view follows editor content |
| 3xl | 64px | Reserved for page-level spacing only; avoid inside compact admin panels |

Exceptions: 44px minimum touch target for text buttons, inputs, selects, checkboxes, and destructive actions; 36px round icon-only buttons only in dense tables/action rows where an accessible label is provided; 8px border radius for cards, panels, inputs, and text buttons; pill radius only for compact status pills and circular icon buttons.

|------|-------|-------|
| Dominant (60%) | `#f7f8f6` | Page background and quiet admin canvas |
| Secondary (30%) | `#ffffff` | Panels, image tiles, form sections, review control surfaces |
| Accent (10%) | `#25636a` | Primary action, active tab, selected image, focus outline, primary-image border, active overlay toggle |
| Destructive | `#b42318` | Destructive actions and destructive confirmations only |
| Warning | `#9a6700` | Dirty state, cleanup warning, preview warning, stale public-current state |
| Border / Divider | `#d7ddd5` | Panel borders, table rules, field borders, review split divider |
| Muted Text | `#626862` | Helper text, metadata, inactive statuses |

Accent reserved for: `Save adjustments`, `Review image`, active tab, selected image tile, focus-visible outlines, active overlay/view-mode toggles, primary-image border, success status text, and same-origin preview retry action. Do not use accent for every link, every badge, or decorative background.

The palette must stay operational and restrained. Do not add purple/blue gradients, decorative orbs, oversized hero treatment, or marketing-style section cards.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | Save adjustments |
| Image tile CTA | Review image |
| Empty state heading | No images uploaded yet. |
| Empty state body | Upload an image for this item, then review the private preview before publishing. |
| Unsaved item state | Save the item before uploading images. |
| Private-only state | Private image only. Publish when this item is ready for the public catalog. |
| Unpublished comparison state | Public version is behind the private image. Publish after review to update the public derivative. |
| Preview loading state | Loading private preview. |
| Preview error state | Preview unavailable. Retry the preview or replace the image; provider details are hidden from the browser. |
| Auto-assist unavailable state | Auto correction could not find reliable edges. Adjust the corners manually. |
| Save success | Adjustments saved privately. Publish changes when this image is ready for the public site. |
| Save error | Adjustments did not save. Keep this page open, review the controls, and try again. |
| Reset success | Adjustments cleared. The original upload is unchanged. |
| Destructive confirmation | Remove image: Remove this image from the item and queue cleanup of the private original? This cannot be undone from the admin UI. |
| Destructive confirmation | Reset adjustments: Clear saved crop, rotation, pan, and perspective correction for this image? The original upload stays unchanged. |
| Dirty cancel confirmation | Discard unsaved image edits and return to the item editor? |

Copy must stay direct and operational. Browser-visible error copy must not include Object Storage URLs, bucket names, namespaces, object keys, image UUIDs, original filenames, filesystem paths, Oracle details, or provider diagnostics.

## Interaction Contract

### Admin Image Tiles

Each saved image tile must show a private, authenticated, same-origin thumbnail by default. The tile layout must remain a compact repeated item, not a nested card.

Tile content order:

1. Stable preview frame with `aspect-ratio: 4 / 3`, image `object-fit: contain`, and a neutral review matte.
2. Status row with `Primary`, `Supporting`, `New`, `Unpublished changes`, `Adjustment saved`, or `Preview unavailable` as compact pills.
3. Alt text or `No alt text recorded.`
4. Safe metadata already shown today: content type and byte size only.
5. Actions: `Review image`, `Mark primary`, `Replace image`, `Remove image`, and `Retry cleanup` when applicable.

Preview URLs must be opaque same-origin admin URLs. The DOM must never render direct Object Storage URLs, bucket/object identifiers, original filenames, public image UUIDs, or unpublished media paths.

### Focused Review View

Use a dedicated review view reached from `Review image`; do not put adjustment controls inline on the image tile.

Desktop layout:

| Region | Contract |
|--------|----------|
| Header | Back to item, item title, image role/status pills, `Save adjustments`, `Discard image edits`, `Reset adjustments` |
| Preview stage | Full-width within the view column, stable `aspect-ratio: 4 / 3`, neutral matte, contain image, no layout shift while loading |
| Controls | Right-side control column, 320px target width, no nested cards |
| Comparison | Segmented control for `Latest`, `Before / After`, and `Split`; default to `Latest` |

Mobile layout: single column; header actions wrap cleanly; controls follow the preview stage; sticky save bar may become static below 760px as the existing admin CSS already does.

### Adjustment Controls

Use familiar controls, not text-heavy explanations:

| Control | UI Contract |
|---------|-------------|
| Rotation | Slider plus numeric stepper/input, bounded to small correction range |
| Zoom / Crop | Slider plus reset-to-fit button |
| Pan | Directional icon buttons or drag on preview; numeric state remains hidden unless useful for validation |
| Perspective / Deskew | Four visible corner handles on the preview, keyboard focusable, with a `Detect edges` secondary action |
| Overlays | Toggle buttons for `Grid`, `Centerline`, and `Edges`; multiple overlays may be active |
| Comparison | Segmented control; split view uses a draggable divider and a visible center rule |

Edits are draft-local until `Save adjustments`. `Discard image edits` abandons unsaved edits. `Reset adjustments` clears saved adjustment metadata after confirmation. Saved changes update private admin previews immediately, record pending-change/edit-history state, and become public only through the normal publish flow.

### Visual States

| State | Visual Contract |
|-------|-----------------|
| No image | Use existing empty-state text in the image grid; no blank preview frame |
| Loading | Fixed-height skeleton/matte inside the preview frame; no spinner-only layout |
| Private only | Show private preview and `New` or `Private only`; do not reserve an empty public comparison pane |
| Public current available | Allow `Before / After` and `Split` comparison between private-latest and public-current |
| Public current stale | Show warning pill and explain publish is needed |
| Dirty draft | Sticky action band uses `#eef2ed` background and warning text; publish actions remain disabled until save |
| Preview failure | Redacted error, retry action, replace action context; no provider detail in browser-visible copy |
| Auto-assist low confidence | Preserve manual handles, show warning copy, do not block saving valid manual correction |

### Accessibility

All controls must be keyboard reachable. Focus-visible outlines use `2px solid #25636a` with `3px` offset. Icon-only buttons require accessible names. Corner handles require labels such as `Top left corner`, `Top right corner`, `Bottom right corner`, and `Bottom left corner`. Overlay and comparison controls must expose selected state with `aria-pressed` or equivalent. Status messages use existing `role="status"` or `role="alert"` patterns.

## Privacy and Cache Contract

Admin preview responses must be authenticated, same-origin, and `Cache-Control: no-store`. Cloudflare/CDN rules must bypass `/admin` and `/admin/api/*`; the admin UI must not rely on browser storage for draft recovery.

Generated public derivatives must continue to use public-safe fingerprinted `/media/*` paths. Adjustment metadata must be part of the derivative cache key so saving only crop/rotation/pan/perspective still produces new public bytes and a new public media fingerprint after publish.

HTML and JSON remain rollback-friendly. Do not design UI flows that require a manual CDN purge for routine image adjustment.

---

## Operational Surfaces

Phase 8 includes security patching and repo/CDN posture work, but those surfaces should remain documentation, CI, GitHub issue/report, and operator-runbook experiences. Do not add an admin dashboard for security patching or CDN management in Phase 8.

Security patch issue/report UI contract:

| Element | Contract |
|---------|----------|
| Summary | Concise package count, severity/CVE count where enrichment is available, and next action |
| Package rows | Exact package specs remain the approval/drift source of truth |
| Advisory detail | Short summaries and links only; do not copy large advisory bodies |
| Enrichment failure | Explain that package inventory is valid and advisory enrichment failed; preserve approval guardrails |
| Drift | Stale approval state must be visibly removed when package set changes |

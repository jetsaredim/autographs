## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Private catalog/media -> public static release | Validated adjustment metadata and private original bytes influence generated public WebP files, but private fields cannot cross into public JSON, HTML, manifests, or paths. |
| Derivative cache -> candidate release | Checksum-backed and byte-hashed legacy keys select cached bytes; candidate fingerprint validation recomputes a path from whichever bytes it receives, so cache payload integrity must be checked at `DerivativeCache::read`. |
| Live operator/admin API -> public Caddy preview | The credential-gated smoke writes a temporary private adjustment, then checks public release timing and cleans up private media. |

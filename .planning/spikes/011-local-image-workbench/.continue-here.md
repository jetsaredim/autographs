## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Restarting an old embedded binary | Tests compiled successfully, but the standalone server still served stale JavaScript and CSS. | blocking | Run `cargo build --release`, restart the sole process, then `curl` for a newly added asset marker. |
| Port hopping or concurrent workbenches | Four revisions previously ran across ports 8787–8790, making UAT results ambiguous. | blocking | Stop the existing process and verify exactly one listener on 8788 before testing. |
| Debug-mode UAT | Full-resolution processing appeared broken because each render took about 27 seconds. | blocking | Always launch `target/release/autographs-image-workbench`. |
| Treating a thin border as unframeable | A sub-3% band cannot meet the target, but excess background on one side can still be trimmed to recenter it. | advisory | Separate target framing from explicitly labeled constrained recentering. |

## Critical Anti-Patterns (do NOT repeat these)

- Do not assume a successful test compile refreshed the standalone workbench binary. Build the release executable explicitly and verify the served assets.
- Do not start a second workbench on another port. Stop the old process and reuse 8788.
- Do not treat unstable fine-edge fits as authority over reliable coarse geometry; fine fits are optional precision enhancement.
- Do not use a manual measurement boundary to prescribe source edits. It may drive explicitly confirmed framing assessment, while alignment prescriptions still require reliable automatic geometry.
- Do not claim cropping creates missing background. Constrained recentering only trims excess real pixels.
